工廠配置 UI（方案 A：Type + 台數，自動命名）

你輸入「機台種類、台數、speed」，系統會自動生成 machines，並讓 route 用下拉選單選 type，避免打錯字。

輸出：config.json

1) 機台種類設定 type × count × speed

type（類型）
台數
speed（倍率）

命名規則：type_1, type_2…（例如：加工_1, 加工_2）。
speed 可輸入單一值（套用全部），或用逗號分隔多個值（每台不同）：例如 1, 1.5。

2) 產品與流程（route） type 下拉會隨新增即時更新

下載後的 config.json 會包含：machines（展開後每台各自 speed）與 products（route 用 type）。
